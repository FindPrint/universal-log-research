# Scope of the public source repository - V9 update

This is an additive update to the public source repository. V9 publishes the ctDNA literature comparison, v6.0.1 patient-group compatibility audit and its reproducible static-audit script, the corrected attribution for the 70-patient ctDNA study, and two unsent data-request drafts. The V9 publication manifest records the exact included files and SHA-256 digests.

No patient-level data were obtained or added. No author contact was sent. No clinical pipeline run was performed on the ctDNA studies. The V8 source audit remains in the repository history; the V9 audit explicitly corrects the V8 citation. The 70-patient study with DOI 10.3389/fonc.2022.902177 is by Kirchweger et al. (2022), while Schlick et al. is a separate 2021 publication with DOI 10.1016/j.pan.2021.09.004.

## Excluded from this source repository

The local `.venv`, generated full-project PDF and ZIP bundles, patient-level restricted-access data, and unverified source data are excluded. Project documentation and results are CC BY 4.0; code is MIT; cited datasets and articles keep their own terms.

## Research status

The v6.0.1 audit is a code-compatibility result only. It found no patient-group argument or group-aware handling in the core entry point. It is not a clinical result, treatment recommendation, efficacy claim, or cure claim.
