3. Synthese actionnable ARN / CRISPR / proteine
3.1 Fenetre conformationnelle KRAS G12D (MD)
• T0 environ 76 ns = moment de changement de regime (ouverture de switch / accessibilite de poche).
• Priorite design : stabiliser l'etat inactif avant T0 ou cibler la poche dans la fenetre T-1-T0.
• Priorite CRISPR : timing de l'edition/base-editing quand la structure est la plus permissive.
• Priorite ARN : combiner siRNA/ASO KRAS avec un agent qui maintient l'etat le plus sensible.
3.2 Fenetre transcriptomique EMT / resistance (scRNA)
• T0 environ Progression 0.566 = point de bascule vers programme mesenchymal + resistance (EGFR, YAP).
• Priorite : intervenir avant 0.50-0.55 avec siRNA/ASO ou CRISPR sur SNAI1 / ZEB1 / YAP / EGFR.
• Apres 0.60-0.70 l'efficacite attendue du knockdown chute fortement.
• Biomarqueur candidat : score composite EMT + EGFR/YAP pour alerte precoce.
3.3 Message transversal
Le pipeline a fourni deux coordonnees critiques coherentes (direction UP, regime de divergence) sur deux modalites differentes. Il ne
propose pas de molecule ni de sequence guide ; il reduit l'espace de recherche pour le design de poches, le timing ARN et le timing
CRISPR.
4. Protocole de validation experimentale minimal
A. MD / structure : mesurer volume de poche / SASA / distances switch avant T-1, entre T-1 et T0, apres T0 sur trajectoires reelles.
Hypothese : accessibilite change significativement autour de 70-80 ns.
B. Organoides PDAC : traiter (siRNA/CRISPR anti-SNAI1/ZEB1/YAP/EGFR) a Progression environ 0.35, 0.52, 0.75. Lire survie,
marqueurs EMT, resistance. Hypothese : efficacite nettement plus elevee avant T0.
Critere de succes minimal : difference d'effet biologique >= 2x entre fenetre pre-T0 et post-T0 sur au moins un axe.
